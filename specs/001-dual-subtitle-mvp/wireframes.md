# UI 와이어프레임: Dual Subtitle MVP

**Feature**: [spec.md](./spec.md)

**Created**: 2026-05-27

**Status**: Draft

본 문서는 [spec.md](./spec.md)의 User Story 1·2·3과 헌법 / 프론트엔드 가이드를 반영한
**저충실(low-fidelity) 와이어프레임**이다. 픽셀 정확한 디자인이 아니라 **레이아웃과
정보 위계, 인터랙션 지점**의 합의를 위한 산출물이다. 시각 디자인(컬러·타이포·간격
토큰)은 `/speckit-plan` 이후 디자인 시스템 단계에서 확정한다.

## 전역 원칙

- **데스크탑 우선**: 기준 폭 `1280px` (콘텐츠 max `1024px`, 좌우 여백 자동)
- **다크 모드 우선**: 배경 `#0B0B0F` 계열, 본문 `#E6E6EB`, 보조 `#9CA3AF` 계열 (확정값은 plan에서)
- **장기 작업 가시화**: 모든 진행 상태는 **단계 인디케이터 + 텍스트 라벨 + (가능 시) 진행률**의 3중 표현
- **Minimal modern UI**: shadcn/ui 컴포넌트 기준, 1픽셀 보더·은은한 surface elevation
- **표기 규칙**: 사용자 가시 문자열은 한국어, 식별자/상태 토큰은 영문 그대로
- **접근성 기본선**: 모든 인터랙티브 요소는 키보드 접근 가능, 명도 대비 ≥ 4.5:1
- **단축키 (MVP 후보)**: `/` URL 입력 포커스, `Space` 재생 토글, `S` 자막 토글, `R` 원·번역 순서 전환

## 화면 인벤토리

| ID | 화면 | 관련 User Story | 접근 경로 |
|----|------|------------------|------------|
| S1 | 메인 페이지 (URL 입력 + 최근 작업) | US1 시작점 · US3 | `/` |
| S2 | 작업 상세 페이지 (진행 상황) | US2 | `/jobs/:id` (처리 중) |
| S3 | 재생 페이지 (dual subtitle 영상) | US1 완료 후 · US3 진입 | `/jobs/:id` (완료) |
| C1 | 공통 상단 헤더 | 전 화면 | — |
| C2 | URL 거절 / 실패 토스트 | 전 화면 | — |
| C3 | 빈 상태 (최근 작업 없음) | S1 | — |

> S2와 S3은 동일한 URL이지만 작업 상태에 따라 렌더링되는 컴포넌트가 다르다 (`processing` vs `completed`). `failed` 상태는 S2에 실패 패널이 추가된 형태.

## C1 — 공통 헤더

```
┌────────────────────────────────────────────────────────────────────────┐
│  ◇ Bilingual Subtitle Studio              [ 새 작업 ]   [ 최근 작업 ▾ ] │
└────────────────────────────────────────────────────────────────────────┘
```

- 좌측 로고/제품명은 클릭 시 `/`로 이동
- `새 작업` 버튼은 S2/S3에서 다시 입력 화면(S1)으로 빠르게 돌아가는 단축
- `최근 작업 ▾`은 드롭다운 (최대 5건 + "전체 보기")

**관련 스토리**: US1 진입점, US3 (최근 작업 목록), 헌법 — 빠른 응답·실시간 가시화

### 인터랙션 노트

- **URL 입력**: 페이지 진입 시 자동 포커스. 붙여넣기 즉시 클라이언트 측 형태 검증, 통과 시 `시작` 버튼 활성화. 거절 시 입력 아래에 빨간 보조 텍스트 (작업 미생성, 헌법 보안 FR-002/031).
- **시작 버튼 클릭**: 작업 제출 API 호출 → 응답 1초 이내 (SC-007) → 즉시 S2로 이동.
- **동일 URL 재요청**: 서버가 기존 완료 작업을 반환하면 모달 "이미 처리된 영상입니다. [기존 결과로 이동] [새로 처리]" 노출 (Edge Case + FR-004).
- **최근 작업 카드**: 상태에 따라 우측 액션이 달라짐.
  - `completed` → `[재생 ▶]` (S3로 이동)
  - `pending`·`downloading`·`subtitle_processing`·`translating`·`rendering` → `[상태 ▶]` (S2로 이동)
  - `failed` → `[상세 →]` (S2의 실패 패널)
- **자동 갱신**: 진행 중 카드의 진행률·단계는 5초 이내 반영 (SC-002).

### 빈 상태 (C3)

```
   📺  아직 처리한 영상이 없습니다.
       위에 YouTube URL을 붙여넣고 시작해 보세요.
```

## S2 — 작업 상세 페이지 (진행 상황 / 실패)

**관련 스토리**: US2, US1·US3에서 처리 중 / 실패 진입.

```
┌────────────────────────────────────────────────────────────────────────┐
│  C1 헤더    ← 뒤로                                                      │
├────────────────────────────────────────────────────────────────────────┤
│  ┌──────────────────┐  「日本語で学ぶ経済」                              │
│  │     [썸네일]      │  채널: ABC  ·  길이 12:34  ·  ja → ko             │
│  │                  │  자막 출처: 수동(ja)        제출: 2분 전           │
│  └──────────────────┘                                                  │
│                                                                        │
│  단계 진행                                                              │
│  ●━━━━━●━━━━━●━━━━━◐━━━━━○━━━━━○                                       │
│  대기   다운  자막  번역   렌더  완료                                    │
│                  ↑ 현재                                                 │
│                                                                        │
│  현재 상태:  translating  (chunk 12 / 26)            ▓▓▓▓▓▓▓░░░░ 46%   │
│  예상 남은 시간: 약 3분                                                  │
│                                                                        │
│  ──── 단계별 로그 ────                                                  │
│  ✓ pending                  09:31:02  · 작업 접수                       │
│  ✓ downloading              09:31:04  · mp4 다운로드 완료 (38 MB)        │
│  ✓ subtitle_processing      09:31:22  · 수동 ja 자막 추출 (143 cues)    │
│  ⏳ translating             09:31:30  · 청크 12/26 진행 중               │
│  · rendering                                                            │
│  · completed                                                            │
│                                                                        │
│  [ 작업 취소 ]                                              [ 자세히 ▾ ]│
└────────────────────────────────────────────────────────────────────────┘
```

### 실패 시 패널 차이

```
  ❌ 실패: 자막을 찾을 수 없습니다
     이 영상에는 한국어 / 일본어 자막이 없습니다.
     향후 음성 인식(STT) 지원이 추가될 예정입니다.

     실패 단계: subtitle_processing
     발생 시각: 09:31:22

     [ 새 영상으로 다시 시도 ]   [ 동일 URL 재시도 ]
```

### 인터랙션 노트

- **단계 인디케이터**: `pending → downloading → subtitle_processing → translating → rendering → completed`의 6노드. 현재 노드는 회전 인디케이터, 이전 노드는 ●, 미래 노드는 ○ (FR-024).
- **실시간 갱신**: 사용자가 페이지를 새로고침하지 않아도 단계 / 진행률이 5초 이내 갱신 (US2 / SC-002). 폴링 vs SSE/WebSocket 선택은 plan에서 결정 (사양 비종속).
- **작업 취소**: 워커 작업은 cancellable (헌법 FR-028). 취소 시 상태는 `failed`로 전이하되 사유는 "사용자 취소"로 노출.
- **`자세히 ▾`**: 펼치면 메타데이터(자막 출처 상세, 청크 수, 재시도 횟수 등)와 `request_id`가 보임 — 디버깅/문의용.
- **완료 직후**: 상태가 `completed`로 바뀌면 자동으로 S3로 라우팅 또는 `[▶ 지금 재생]` 큰 CTA가 등장 (UX 결정은 디자인 검토 단계에서).

### 인터랙션 노트

- **자막 overlay**: 영상 하단 18% 영역에 두 줄, 가운데 정렬. 행간은 1.4. 폰트 크기는 영상 폭에 비례 (반응형).
- **자막 표시 토글**: `[ 자막 표시 ◉ ]` 또는 단축키 `S`. 끄면 영상만 재생 (FR-022).
- **순서 전환**: 원문 위 / 번역문 위 즉시 전환 (FR-023, 단축키 `R`). 기본값은 `원문 위`이며 사용자 선택은 로컬에 저장 (호스트 단위).
- **자막 미리보기 리스트**: 시간 코드와 두 줄 텍스트. 클릭 시 해당 시점으로 seek. 현재 재생 cue는 강조 (배경 surface elevation +1).
- **다운로드 버튼**: SRT / VTT 두 형식 모두 다운로드 가능 (FR-018).
- **자동 자막 출처일 때**: 헤더 라인에 `🤖 자동 자막 기반` 뱃지를 표시 (Edge Case — 사용자가 품질 한계 인지).
- **반응형 한계**: MVP는 desktop-first. 1024px 미만에서는 자막 컨트롤이 한 줄에서 두 줄로 자동 줄바꿈하지만 모바일 최적화는 본격 적용하지 않는다 (MVP 제외).

## C2 — 공통 토스트 / 인라인 메시지

```
[성공]   ✓ 작업이 접수되었습니다. 진행 화면으로 이동합니다.
[정보]   ℹ 이미 처리된 영상입니다. [기존 결과로 이동]
[경고]   ⚠ 자동 자막은 정확도가 낮을 수 있습니다.
[오류]   ✕ 유효한 YouTube 영상 URL이 아닙니다.
```

- 토스트는 우측 하단 4초 자동 사라짐 (오류는 6초)
- 인라인 오류 (URL 입력 옆 보조 텍스트)는 사용자가 입력을 수정할 때까지 유지

## 컴포넌트 후보 (plan 단계 입력)

본 와이어프레임에서 다음 컴포넌트 추출이 자연스럽다. plan 단계의 `component hierarchy`
정의 시 출발점으로 사용:

- `<AppHeader />`
- `<UrlInputCard />` (입력, 검증, 시작 버튼)
- `<JobListItem />` (썸네일 + 메타 + 상태 뱃지 + 액션)
- `<StatusBadge />` (`pending`/`downloading`/.../`completed`/`failed` 6+1 variant)
- `<StageProgressBar />` (6 노드 인디케이터)
- `<StageLog />` (단계별 타임라인)
- `<VideoPlayer />` (HTML5 video + overlay slot)
- `<DualSubtitleOverlay />` (두 줄 자막 렌더)
- `<SubtitleControls />` (토글 / 순서 / 형식)
- `<SubtitleCueList />` (클릭하여 seek)
- `<Toast />` / `<InlineError />`
